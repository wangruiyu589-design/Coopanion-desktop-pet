# Coopanion Desktop Pet

Coopanion 桌面宠物 —— 一个开源的桌面伙伴项目。
*Coopanion Desktop Pet — an open-source desktop companion pet.*

## 项目简介

Coopanion 是一个桌面宠物（Desktop Pet）项目，目标是在桌面上运行一个可互动的伙伴形象。
